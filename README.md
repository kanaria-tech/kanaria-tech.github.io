# kanaria-tech.github.io
Kanaria Tech webpage: https://kanaria-tech.github.io



## QR code

`qr/` holds QR codes that open https://kanaria-tech.github.io:

- `kanaria-links-qr.svg`: plain, scalable, use this for print
- `kanaria-links-qr.png`: plain, 1480 px
- `kanaria-links-qr-logo.png`: with the Kanaria logo in the centre (error correction H), 1640 px

Print at 2 cm wide or larger and keep the white border.
